# Ролики «что ждёт знак до конца 2026»

Вертикальное видео 1080×1920 из настоящего расклада «Нити»: загрузка терминала, три карты
(октябрь — что отпустить, ноябрь — что придёт, декабрь — с чем войдёшь в 2027), финал с выводом терминала.
Приложение не затрагивается: сцена живёт в `reel.html` + `src/reel/`.

## Что нужно

- Node.js (для Vite и записи), ffmpeg, Google Chrome.
- Python 3 с torch, numpy, scipy — только для голоса терминала (Silero). Модель:
  https://models.silero.ai/models/tts/ru/v4_ru.pt
- `GEMINI_API_KEY` — голос диктора (Gemini TTS, голос Erinome).

## Как собрать ролик для знака

1. Вытянуть карты (зерно — знак + дата, поэтому расклад воспроизводим):
   `npx tsx scripts/reel/plan.ts rak 2026-10-11 "<папка роликов>"`
   Знаки: oven, telets, bliznetsy, rak, lev, deva, vesy, skorpion, strelets, kozerog, vodoley, ryby.
2. Написать `texts.json` в папке ролика:
   ```json
   {
     "terminal": {
       "open": "Соединение установлено. Запрос: Рак. Целостность нарушена.",
       "err": "Ошибка. Повторная попытка.",
       "close": "Чтение завершено. Ожидаю следующий запрос."
     },
     "cards": [{ "screen": "…", "voice": "толкование для диктора" }, …]
   }
   ```
   `err` нужен, только если в раскладе есть повреждённая карта. Без неё в `open` — «Обнаружены помехи.» или «Целостность в норме.»
3. Озвучить: `SILERO_MODEL=… GEMINI_API_KEY=… python scripts/reel/audio/voice.py "<папка ролика>"`.
   Бесплатный лимит Gemini TTS — 10 запросов в день на модель (`TTS_MODELS` задаёт порядок моделей).
   Уже озвученные толкования (`voice/raw/card*.wav`) не перезапрашиваются.
4. Записать: `FFMPEG=… npx tsx scripts/reel/record.ts "<папка ролика>"` → `<знак>.mp4` и `cover.jpg`.

## Как устроено

- `src/reel/timeline.ts` — расписание в мс по длинам озвучки; по нему же собираются картинка и звук.
- `src/reel/YearReel.tsx` — кадр целиком вычисляется из времени t, поэтому запись ровная и повторяемая.
- `scripts/reel/record.ts` — Vite + headless Chrome (CDP): кадр за кадром → ffmpeg.
- `scripts/reel/audio/` — обработка голосов (терминал: тёмный зал + гул; диктор: уличный громкоговоритель),
  субтитры по паузам в речи, звуковые эффекты и общий гул (`mix.py`).

## Трейлер «Камеры»

Отдельный ролик для профиля: стол гадалки через камеры наблюдения, круг эмблем, монтаж каналов,
тишина и Дьявол крупно, терминал, титр. Голос — только диктор.

1. В папке трейлера — `texts.json` с репликами диктора в `cards` (без `plan.json`: по нему запись понимает, что это трейлер).
2. Озвучить: `voice.py "<папка трейлера>"` — диктор на `gemini-3.1-flash-tts-preview`, как в роликах про знаки.
3. Записать: `record.ts "<папка трейлера>"` → `trailer.mp4`. Звук целиком собирает `audio/trailer_mix.py`.

Расписание — `src/reel/trailer.ts`, сцена — `src/reel/TrailerReel.tsx`.
