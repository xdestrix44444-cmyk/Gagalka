# Нить · нейро-таро

Таро-компаньон в Telegram Mini App в пиксельном стиле. Первая версия: карта дня, расклад на три карты, дневник, натальные карты. В колоде все 78 карт, но в игре пока только те, для которых есть рисунок.

## Запуск

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run server     # сервер ИИ-толкований на :8787 (во втором терминале)
npm test           # тесты логики вытягивания карт
npm run build      # проверка типов и сборка в web/dist
```

Просмотр всей колоды: `npm run dev`, затем `/deck.html`.

### ИИ-толкования

Толкования пишет Claude Sonnet 5.5 через сервер `web/server`. Ключ хранится только на сервере:

```bash
cd web
cp .env.example .env   # и вставьте ANTHROPIC_API_KEY
npm run server
```

Без ключа (или если сервер не запущен) приложение показывает временные тексты колоды.

## Устройство

- `web/src/deck.ts` — колода из 78 карт и временные тексты толкований (до подключения ИИ). `ACTIVE_IDS` — карты, которые сейчас выпадают.
- `web/src/minor.ts` — данные 56 младших арканов.
- `web/src/draw.ts` — вытягивание карт. Карты выбирает код через `crypto.getRandomValues`, ИИ их только толкует.
- `web/src/sprites.ts` — карты из рисунков: `art-src/` (исходники) → `web/src/art/img/` (JPG) → шаблон `art/preset.ts` (рамка, номинал, имя). Новый рисунок подключается в `ART` здесь и в `ACTIVE_IDS`.
- `web/src/PixelCard.tsx` — карта с двумя сторонами, переворот и тасование; стили ритуала в `styles.css`.
- `web/server/` — сервер толкований: `prompt.ts` (правила ИИ-таролога), `index.ts` (POST /api/reading, поток текста, лимит запросов).
- `web/src/AiText.tsx` — толкование на экране: текст появляется по мере генерации, при сбое — временный текст.
- `web/src/natal/` — натальные карты (карта рождения, небо сегодня, совместимость, экскурсия, аркан рождения, картинка для сторис): `chart.ts` (планеты через astronomy-engine, Асцендент, дома Плацидус/Порфирий, аспекты, перевод местного времени в UTC), `cities.ts` (города России с часовыми поясами), `portrait.ts` (связный портрет по узорам карты), `Wheel.tsx` (анимированный круг со вторым кольцом и приближением), `relations.ts` (транзиты и совместимость), `meanings.ts` (смысл при касании), `tour.ts`, `share.ts`, `people.ts` (сохранённые люди). Эмблемы знаков и планет: `npm run emblems` из `art-src/emblems`.
- `web/src/ui/` — оформление «проклятый терминал»: фон с глазами (`Haunt.tsx`), экран входа (`Boot.tsx`), строка статуса, пиксельные рамки (`frames.ts`). Звук синтезируется в `web/src/sound.ts`. Шрифты встроены через `@fontsource`.
- `web/src/storage.ts` — карта дня и дневник в `localStorage`.
- `web/src/telegram.ts` — интеграция с Telegram WebApp.

Ключи и токены не храним в репозитории: только в переменных окружения.
