# Нить · нейро-таро

Таро-компаньон в Telegram Mini App в пиксельном стиле. Первая версия: карта дня, расклад на три карты, дневник. В колоде все 78 карт, но в игре пока только те, для которых есть рисунок.

## Запуск

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # тесты логики вытягивания карт
npm run build      # проверка типов и сборка в web/dist
```

Просмотр всей колоды: `npm run dev`, затем `/deck.html`.

## Устройство

- `web/src/deck.ts` — колода из 78 карт и временные тексты толкований (до подключения ИИ). `ACTIVE_IDS` — карты, которые сейчас выпадают.
- `web/src/minor.ts` — данные 56 младших арканов.
- `web/src/draw.ts` — вытягивание карт. Карты выбирает код через `crypto.getRandomValues`, ИИ их только толкует.
- `web/src/sprites.ts` — карты из рисунков: `art-src/` (исходники) → `web/src/art/img/` (JPG) → шаблон `art/preset.ts` (рамка, номинал, имя). Новый рисунок подключается в `ART` здесь и в `ACTIVE_IDS`.
- `web/src/PixelCard.tsx` — карта с двумя сторонами, переворот и тасование; стили ритуала в `styles.css`.
- `web/src/storage.ts` — карта дня и дневник в `localStorage`.
- `web/src/telegram.ts` — интеграция с Telegram WebApp.

Ключи и токены не храним в репозитории: только в переменных окружения.
